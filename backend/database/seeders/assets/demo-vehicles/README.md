# Synthetic demo galleries

These bundled PNGs were created with the built-in image generation tool for local development only. They are not photographs of real sale listings, authoritative trim specifications or manufacturer-supplied media.

|---|---|---|---|

Order: front three-quarter, rear three-quarter, side, front detail, wheel, cabin, rear seats. Brand/model cues were visually checked; synthetic details can differ from real equipment. Do not infer matching/safety attributes from these images.

Prompt set: one realistic landscape studio image of the named silver 2019 model per view, soft neutral gray lighting, no people, watermark, text or readable plate; explicitly fictitious software test data. Each model uses its own gallery. LocalDevSeeder copies each gallery through VehiculoFotos::store so removing one car's images does not remove another car's files.
